## 책 추가하는 법

`books.js`의 `const D=[ ... ];` 맨 아래에 한 줄을 추가합니다. 바로 위 줄 끝에 쉼표(`,`)가 있는지 확인하세요.

```js
[2027, "01.08", "책 제목", "저자", 320, "영어", 1818, "문학", 0, 1, 0, "장편소설", 843]
```

| 순서 | 항목 | 적는 법 |
|---|---|---|
| 1 | 모임 연도 | `2027` |
| 2 | 모임 날짜 | `"01.08"` (월.일, 두 자리) |
| 3 | 제목 | |
| 4 | 저자 | |
| 5 | 쪽수 | 읽은 판본 기준 |
| 6 | 원어 | 실제 언어 이름. 영어·한국어·독일어·프랑스어·일본어·스페인어·러시아어 외에는 색이 '기타'로 묶임 |
| 7 | 원작 발표연도 | 번역본이 아니라 원작이 처음 나온 해 |
| 8 | 분류 | `"문학"` 또는 `"논픽션"` |
| 9 | 노벨문학상 수상 작가 | 1 / 0 |
| 10 | 여성 저자 | 1 여성 · 0 남성 · 2 위원회·공저 |
| 11 | 노벨상 수상연도 | 없으면 0 |
| 12 | 세부 장르 | 장편소설 · 소설집 · 희곡 · 시 · 동화·청소년 · 에세이·회고 · 과학·의학 · 철학·사상 · 사회·시사 · 역사·인문 · 실용·자기계발 |
| 13 | KDC | 한국십진분류 번호 (예: 영미소설 843, 독일소설 853) |

권수, 쪽수, 연도별 통계, 서가, 전체 목록은 자동으로 다시 계산됩니다.
새해 책을 처음 넣으면 그해가 '진행 중'으로 표시됩니다.

### 새해가 되면

`books.js` 맨 아래 `ERA_NOTES`에서 그해 이름과 소개를 채웁니다. 비워 두면 권수만 표시됩니다.

```js
2027:["시기 이름","한두 문장 소개"],
```

### 자동으로 바뀌지 않는 것

- `index.html` 본문 해설 중 손으로 쓴 문장 (예: "실용·자기계발 4권 중 3권은…")
- `og-image.png`와 미리보기 문구 (권수를 넣지 않아서 책을 추가해도 그대로 써도 됨)
- `star.html`의 대출건수 데이터
